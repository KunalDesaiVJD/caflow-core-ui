How it works

Each rule carries a detection_logic spec (e.g. {"check":"single_txn","direction":"debit","threshold":20000}). The interpreter dispatches it to a handler, renders the rule's audit-query template, and writes a finding. A finding can be raised as a client query, where a second person approves before it is sent.

Coverage — 50 automated, 69 advisory

Tier A — deterministic now (20 checks / 37 rules) Tier B — computable now (8 checks / 13 rules) Advisory — needs facts/uploads (69 rules)

Advisory rules (ageing, market-rate, ROC filings, physical verification, etc.) are flagged for manual review, not skipped — they switch to automatic once the fact masters / file uploads (later phases) land.
