2.4 · Opus-drafted client query (maker-checker)

"Raise query" on a finding → the draft query text is AI-written
⧗ Draft "We note a cash payment of ₹45,000 to Ramesh Transport on 12-Aug-2025. As payments exceeding ₹35,000 to a transporter attract s.40A(3), kindly explain the mode of payment and share the supporting vouchers."
A second reviewer still approves before it can be sent (Phase-1 gate). If the gateway is offline, the draft uses the deterministic rule template instead — the flow is unchanged.

2.5 · "Seen before" (exclusion learning)

A finding that the auditor waived in a prior year, recurring this year
Interest-free advance to director ⧗ Seen before
Learned purely from your own waived findings in other years (same rule + ledger) — no AI, no new tables. Semantic matching via Voyage embeddings is a later upgrade.
