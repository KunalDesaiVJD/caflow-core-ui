No deploy needed

  • Phase 5 is deterministic — no gateway, no API keys, no migration. It works as soon as the v2 flag is on and a client has a trial-balance snapshot.
  • Connectors process the uploaded file in the browser only; nothing is saved.

What the CA should review

  • Benford verdict bands — the Nigrini MAD thresholds (close / acceptable / marginal / nonconforming) and the 50-amount "insufficient" floor.
  • Duplicate rule — is "same amount + date + party" the right signal, or too strict/loose?
  • Reconciliation matching — amount-only is the v1 first pass. Which connectors should get tighter keys (GSTIN for 2B, TAN for 26AS, amount+date for bank)? Do you want uploads persisted (needs a store/migration)?
