No deploy needed

  • Phase 7 is deterministic — no gateway, keys or migration. It populates once the v2 flag is on and the firm's clients have scrutiny findings.
  • Cross-engagement reads are firm-scoped by RLS; it flags the 1,000-finding fetch cap for very large portfolios.

What the CA should review

  • Precision bands — promote ≥ 80% / demote ≤ 30% precision, min 5 actioned — right thresholds?
  • Benchmark bands — "above norm" ≥ 1.5× / "below norm" ≤ 0.5× the portfolio average — right sensitivity?
  • Should demote/promote ever auto-apply? Today it's advisory only (partner action, logged). Do you want a partner-gated "apply" that disables a rule?
